# DINOv3公式重みの配置先

取得済みの **ViT-S/16 (LVD-1689M)** の公式重みをこのディレクトリへ配置する。
UIの既定ファイル名は `dinov3_vits16_pretrain_lvd1689m-08c60483.pth`。
別名の場合はUI「学習環境」の重みパスを変更する。

重みの自動取得・同梱はしない。重みファイルはGit管理対象外。
未配置の場合は学習開始時にエラーとなり、ランダム重みへの代替はしない。

ViT-B/16の比較を行う場合は、取得済みの対応する公式重みを
`dinov3_vitb16.pth`として配置するか、UI「学習環境」のViT-B専用欄に既存パスを指定する。
ViT-S用のファイルとは分ける。Baseの読み込みは形状をstrict検証する。
scratch学習（ViT-S/Tiny/Base・CNN）には事前学習重みは不要で、自動取得しない。
