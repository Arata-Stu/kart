コントローラの識別

軸の割り当て

「検出」を押して対象の軸だけを操作します。その後、静止・各端を保持して「取得」で校正します。反転は負端と正端を交換してください。トリガーはunipolarで静止→0、正端→1です。コード -1 は無効。

出力 / indexABSコード形式負端 (-1)静止 (0)正端 (+1)deadzone生入力

ボタンの割り当て

「検出」の後にボタンを押します。十字キー等の軸にも対応します。軸から割り当てる場合は direction × 生入力 ≥ threshold で押下になります。
